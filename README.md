## 📌 Project Overview

The SOC Final Capstone demonstrates a structured Security Operations Center investigation in an authorized cybersecurity lab environment.

The project brings together endpoint security monitoring, network intrusion detection, alert investigation, event correlation, Indicators of Compromise (IOC) analysis, incident classification, response, and final reporting.

Wazuh provides endpoint and security-event visibility, while Snort provides network intrusion detection. The investigation uses available evidence to assess suspicious activity and document appropriate response actions.

## 🎯 Objectives

- Validate the SOC lab environment and monitoring components.
- Investigate a controlled security event.
- Analyze raw Wazuh alerts and relevant Snort events.
- Build an evidence-based incident timeline.
- Register observed indicators and document their sources.
- Classify the event using evidence and context.
- Document containment, remediation, recovery, and lessons learned.
- Prepare a professional SOC incident ticket and final report.

## 🔍 Investigation Workflow

1. Validate the lab environment.
2. Confirm endpoint agent and monitoring status.
3. Execute a safe, authorized test scenario.
4. Collect and inspect security alerts.
5. Establish an investigation timeline.
6. Correlate endpoint and network events where evidence supports a relationship.
7. Record observed IOCs and their sources.
8. Assess the event and determine its classification.
9. Document response and recovery actions.
10. Prepare the incident ticket, metrics, and final report.
